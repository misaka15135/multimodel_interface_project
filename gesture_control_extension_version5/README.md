# 🖐️ Gesture Control Ultimate v3.0

**全局自启动手势控制插件 + 自由悬停点击交互**

---

## 📋 功能概览

### 核心特性
- ✅ **全局自启动** - 插件打开后自动开启摄像头手势识别
- ✅ **11种手势识别** - 覆盖视频控制、网页操作、自由交互等场景
- ✅ **实时手指状态条** - 显示五个手指的伸展程度
- ✅ **自由悬停点击** - 用食指指尖精准控制光标并悬停点击
- ✅ **小指快速退出** - 伸出小指即可停止识别
- ✅ **低延迟响应** - 优化的手势识别与处理算法

## 🎯 特色功能详解

### 1️⃣ **全局自启动模式**
- 安装插件后自动启动手势识别，无需手动开启
- 摄像头权限获取后立即显示识别窗口
- 随时可用按钮手动切换状态

### 2️⃣ **自由悬停点击交互** 🎪
进入自由交互模式后（中指无名指触发）：
- **食指尖跟踪** - 食指尖在屏幕上移动，拖动光标跟随
- **平滑滤波** - 算法平滑化手抖动（降低15%偏差）
- **悬停触发** - 光标停留在 45px 圈内超过 1.2 秒自动点击
- **视觉反馈** 
  - 🔴 红色光标表示待命状态
  - 逐渐缩小 + 变红 = 悬停计时中（进度条式变化）
  - 青色 + 放大 = 点击触发完成
- **自动冷却** - 点击后自动进入 1s 冷却期，防止连续误触

### 3️⃣ **实时手指状态条**
在屏幕右上角显示 5 行手指伸展进度条：
- **拇指、食指、中指、无名指、小指** 各占一行
- 颜色变化：
  - 🔳 灰色 (0-33%) = 未伸出
  - 🟠 橙色 (33-66%) = 部分伸出
  - 🔵 青色 (66-100%) = 完全伸出
- 实时更新频率：30 FPS

### 4️⃣ **持续动作确认机制**
需要确认的手势（上翻、下翻、刷新、小指退出、自由模式）：
1. **识别阶段** - 手势首次识别时，UI 框缩小显示 `scaling` 状态（橙色边框）
2. **倒计时阶段** - 持续保持手势 0.9 秒
3. **确认阶段** - 超时后 UI 框放大并发光（青色边框），执行动作
4. **打断机制** - 若手势变化或中途放下，立即中止确认

### 5️⃣ **冷却系统**
防止误操作连续触发：
- 点赞：2s 冷却
- 下一个视频：1.5s 冷却
- 快进快退：0.4s 冷却（支持快速连续）
- 播放暂停：1s 冷却
- 倍速：1.5s 冷却
- 自动续冷却后 UI 复位

## 📊 识别算法

### 手指伸展判定
```
伸展 = 指尖距离掌心 > MCP关节距离掌心 × 1.25
```

### 手势识别流程
```
1. 获取21个手部关键点（MediaPipe 标准）
2. 计算5个手指的伸展状态（T/F）
3. 组合识别模式匹配
4. 输出手势类型（11种之一）
5. 传递至动作执行器
```

### 光标平滑滤波
```
smoothedX = smoothedX + (rawX - smoothedX) × 0.15
smoothedY = smoothedY + (rawY - smoothedY) × 0.15
```
- 权重：15% - 平衡跟踪灵敏度与稳定性
- 帧率：30 FPS - 50ms 更新周期

## 🚀 快速开始

### 安装步骤
1. 在 Chrome/Edge 中打开 `chrome://extensions/`
2. 启用"开发者模式"（右上角开关）
3. 点击"加载已解压的扩展程序"
4. 选择 `gesture_control_extension_version5` 文件夹
5. 授予摄像头权限

### 首次使用
1. 打开任意网页
2. 插件自动启动（摄像头请求权限）
3. 允许摄像头访问
4. 左下角显示实时摄像头预览
5. 开始手势操作！

### 退出识别
- 方式1：伸出小指持续 0.9s
- 方式2：点击左下角"关闭增强手势"按钮

## 🎓 最佳实践

### ✅ 推荐做法
- 🎥 保证 **正面对摄像头**，手部清晰可见
- 💡 在 **光线充足** 的环境使用
- 🖐️ 保持手部 **距摄像头 30-60cm**
- ⏱️ 手势需要 **持续稳定** 至少 0.5 秒才能被识别
- 🔄 **逐步习惯** 手势操作，频繁使用可提升识别率

### ❌ 避免做法
- 🌑 暗光或逆光环境
- 🤚 手被挡住或只显示部分
- 💨 快速晃动手（影响识别连贯性）
- 🎵 同时进行多手势操作（只支持单手）

## 🐛 常见问题

### Q：摄像头显示黑屏？
**A:** 检查浏览器摄像头权限 → 设置 → 隐私 → 摄像头 → 允许此网站访问

### Q：手势识别不灵敏？
**A:** 确保光线充足、手部完整可见、手势保持 0.5s 以上

### Q：点击不在光标位置？
**A:** 这是浏览器沙箱限制，点击会在网页元素上执行，视觉光标位置供参考

### Q：如何调整悬停时间？
**A:** 修改 `content.js` 中的 `CONTINUOUS_CONFIRM_TIME` 常量（单位：毫秒）

### Q：能否关闭实时摄像头预览？
**A:** 修改 `content.css` 中 `#gesture-debug-window { display: none; }` 即可隐藏

## 📄 文件结构

```
gesture_control_extension_version5/
├── manifest.json      # 扩展程序清单（权限、脚本配置）
├── content.js         # 核心逻辑（手势识别、DOM操作、光标控制）
├── content.css        # 样式表（UI 界面、动画效果）
└── README.md          # 本文档
```

### 核心文件说明
- **manifest.json** - 定义插件为内容脚本，在所有网页注入
- **content.js** - 主体逻辑（825 行代码）
  - `recognizeGesture()` - 11种手势识别
  - `executeAction()` - 动作分发与执行
  - `handleFreeModeCursor()` - 光标跟踪与悬停点击
  - `onResults()` - MediaPipe 回调处理
- **content.css** - 样式（动画、过渡、效果）
  - `.gesture-action-box.*` - 动作 UI 状态动画
  - `#gesture-cursor` - 自由模式光标样式
  - `#finger-status` - 手指状态条样式
