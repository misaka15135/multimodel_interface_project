## 用户交互技术（期末大作业）
### 整合眼动、手势与语音的网页插件原型

### 简介
- 目标：将眼动（eye-tracking）、手势（gesture）和语音（voice）三模态整合为一个可在网页中使用的插件，长期目标是扩展为手机应用。
- 当前状态：已完成对特定网站的操作想象。

### 使用
- 打开 **multimodel_chrome_extension** 按其README中顺序执行

### 文件结构
- multimodel_chrome_extension/三模态融合控制插件(目标已实现)
- gesture_control_extension_version5/第5版手势识别插件
- head_control_extension/头部控制插件
- mobile/手机端说明与原型建议(未实现)
- voice_control_extension/语音控制插件
- mid_report.pptx/开题答辩PPT
- README
