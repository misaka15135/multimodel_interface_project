# 🎤 声控助手 Voice Control v0.4

**Chrome 浏览器语音控制扩展 — 混合意图引擎 + 上下文记忆 + 多模态融合就绪**

## 📋 功能概览

### 核心特性
- ⚡ **混合意图引擎** — 常用命令本地 0 延迟命中、不调 API、断网可用；LLM 仅兜底复杂/歧义命令
- ↻ **上下文记忆** — 支持追问："继续 / 再来"、"重复"、"撤销"
- 🛡 **鲁棒性** — 识别去重、置信度门、危险动作语音确认、LLM 失败优雅降级
- 🔗 **多模态融合就绪** — 标准事件总线 MMFusion，语音"点这个"可消费手势/眼动指向的目标
- ✅ **唤醒词模式** — 说"小助手"激活，10s 无命令自动休眠
- ✅ **连续对话** — 激活后持续监听，无需反复点击
- ✅ **TTS 语音反馈** — 操作后语音播报确认（默认关闭，可开）
- ✅ **DeepSeek LLM 语义理解** — 自然语言→结构化操作
- ✅ **20+ 种操作** — 导航、缩放、朗读、查找、点赞、评论、指代点击等
- ✅ **B站评论直发** — 支持 B站 API + DOM 双路由

### 模式说明

| 模式 | 指示灯 | 行为 |

## ⚡ 混合意图引擎（v0.4 核心）

每条指令的处理路径：

```
语音 → 去重 → 置信度门 → ┌─ 本地匹配命中? ──是──▶ 直接执行 (0 延迟, 不调 API)
                         └─ 否 / 歧义 ──────────▶ LLM 兜底解析 ──▶ 执行
```

- **本地命中**（约 15+ 常用命令）：滚动、刷新、前进后退、缩放、朗读、查找、点赞、停止…
  反馈右下角带 `⚡本地` 标记，**断网也能用**。
- **LLM 兜底**（带 `☁AI` 标记）：复杂措辞、多义句、本地无法判定时才调用 DeepSeek。
- **歧义保护**：一句里同时命中两个不同动作（如"往下滚动并刷新"）→ 交给 LLM 判定。

## ↻ 上下文记忆与追问

| 说法 | 行为 |
|------|------|
| "继续" / "再来" / "再多一点" | 按上次方向再滚一次 |
| "重复" / "再来一次" | 重做上一条指令 |
| "撤销" / "撤回" / "返回上一步" | 还原上一个可逆动作 |

**撤销机制**：执行前对状态快照（滚动存 `scrollY`、缩放存 `zoom`），撤销即还原——
比"反向滚同样距离"可靠。可撤销：滚动 / 缩放 / 前进后退 / 查找高亮。
不可撤销（会提示）：刷新 / 点赞 / 评论 / 朗读等。

## 🛡 鲁棒性

- **识别去重**：同一句 1.5s 内重复触发自动忽略（Web Speech 偶尔双触发）。
- **置信度门**：识别置信度过低时提示"没听清，请再说一遍"
  （注意：Web Speech 中文常上报置信度 0，此时不拦截，避免误伤）。
- **危险动作确认**：刷新、发表评论前需语音确认——提示"确认要…吗？说'是/确认'"。
- **LLM 失败降级**：本地没命中且 LLM 报错时，提示"暂时无法理解，请换种说法"，不崩溃。

## 🔗 多模态融合（MMFusion）

为后续与**手势**、**眼动/面部**模块融合预留的统一层。详见 [`FUSION.md`](./FUSION.md)。

- 三模态分工：**眼动=注视，手势=选择，语音=命令**（"point + speak"范式）。
- 传输层用 `document` 上的 CustomEvent，**跨扩展/跨 world 互通**（手势是 MAIN world、
  语音是隔离 world，`window` 不相通，只能靠共享 DOM）。
- 语音说**"点这个 / 打开它"** → 从共享上下文 `pointerTarget`(手势) / `gazeTarget`(眼动)
  取目标并点击；**无其他模态时优雅降级**，语音独用完全不受影响。
- **仲裁**：多模态同一动作 500ms 内去重；冲突按优先级（语音 > 手势 > 眼动）。
- 手势同学接入只需 3 步（见 FUSION.md），不改其逻辑骨架。

## 🔧 安装与使用

### 安装
1. Chrome/Edge 打开 `chrome://extensions/`
2. 启用「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `voice_v0.4` 文件夹

### 首次配置
1. 点击右下角 **⚙** 齿轮按钮
2. 输入 DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 获取）
   - 注：本地命中的常用命令**无需 API Key 也能用**；API Key 仅用于 LLM 兜底。
3. （可选）开启 TTS 语音反馈 / 唤醒词模式

### 使用方式
**唤醒词模式（默认开关在设置里）**：点麦克风 → 说"小助手" → 叮咚+绿灯 → 说指令。
**直接模式**：关闭唤醒词 → 点麦克风 → 直接说指令。

```
├── action-registry.js    ② 动作注册表（注册式扩展）
├── intent-matcher.js     ③ 本地意图匹配器（混合引擎快通道）★v0.4
├── llm-client.js         ④ DeepSeek API 语义理解（兜底）
├── speech-recognizer.js  ⑤ Web Speech API 语音识别
├── tts-manager.js        ⑥ TTS 语音合成 + 提示音
├── action-executor.js    ⑦ 内置动作处理器（+ click_target / undo）
├── context-manager.js    ⑧ 上下文记忆 + 撤销栈 ★v0.4
├── ui-manager.js         ⑨ UI 组件（按钮/设置/指示灯）
├── voice-controller.js   ⑩ 主脑：混合管线 + 状态机 + 融合接线
├── voice-content.css     ⑪ 样式表
├── gesture-adapter.js    ⑫ 给手势同学的接入桥（不进本扩展 manifest）★v0.4
├── manifest.json         ⑬ 扩展清单
├── FUSION.md             ⑭ 多模态融合契约 ★v0.4
└── README.md             ⑮ 本文档
```

### 混合处理管线（voice-controller.js）

```
processCommand:
  去重 → 待确认优先 → 置信度门 → 本地匹配
    ├─ 追问(撤销/重复/继续) → 上下文解析
    ├─ 本地命中 → 执行
    └─ 未命中/歧义 → LLM 兜底
  → 指代解析(click_target) → 危险动作确认门
  → buildUndo → 执行 → 记录上下文 → 发布到融合总线 → TTS/Toast 反馈
```

### 多模态融合接口

```js
// 1. 任意模态订阅跨模态事件
window.MMFusion.subscribe((event) => {
  // { source, type, action, params, target, confidence, timestamp, raw }
});

// 2. 发布事件
window.MMFusion.publish({ source:'gesture', type:'command', action:'scroll_down' });

// 3. 写共享上下文（供"点这个"消费）
window.MMFusion.setContext('pointerTarget', { point:{ x:200, y:300 } });

// 4. 语音模块自身的向后兼容 API（v0.3 起）
window.VoiceExt.controller.onEvent((e) => {});
window.VoiceExt.controller.executeAction('scroll_down', { amount: 500 });
window.VoiceExt.controller.getState();
```

## 🚧 已知限制

- 浏览器语音识别在嘈杂环境准确度下降，国内需畅通网络访问 Web Speech 服务。
- 融合事件不跨 iframe；跨 frame 融合暂不支持。
- 指代点击的坐标 selector 在动态 SPA 中可能失效，优先用坐标。
- `tab_new` 可能被浏览器弹窗拦截器阻止。
